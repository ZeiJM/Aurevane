# RETIRED — Mantle terminology

**Status:** Retired by Owner decision on 2026-09-20.

AUREVANE no longer uses **Mantle** as a canonical supernatural power family.

The canonical supernatural fork is now:

```text
UNAWAKENED
   ↓
ASCENDED  ← Ascension
   OR
SEVERED   ← Severence
```

Characters are **Ascended** or **Severed**.

The former Mantle transformation design space is absorbed into **Severence**. It must not be reintroduced as a third named power family.

**Severence** is the intentional AUREVANE spelling.

See `docs/SUPERNATURAL_PATHS.md`, `docs/GAME_MASTER_PLAN.md`, and `docs/ROADMAP.md` for the current authoritative direction.

This file is retained only so historical links do not silently lead future implementation back to the retired design.

# Live World & Master Panel Direction Change

This note records the owner-approved direction added on 2026-08-15.

The project now explicitly treats AUREVANE as a continuously evolving online world whose recurring hook is the player's permanent character build. Live world events, ongoing story operations, delegated staff permissions, and a progressively delivered Master Panel are part of the intended product direction.

Authoritative detail lives in:

- `docs/WORLD.md`
- `docs/MASTER_PANEL.md`
- `docs/ROADMAP.md`
- `docs/TECH_ARCHITECTURE.md`

This change does not expand the scope of the current Phase 0 implementation ticket. It changes future roadmap and architecture expectations so the necessary foundations are not forgotten.

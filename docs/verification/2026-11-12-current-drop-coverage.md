## Independent source audit and correction

A fresh read-only whole-branch audit compared the prepared source against main16883ffd and all three current specifications. It traced actual renderer, projection, settings and teleport consumers rather than relying on generated images or test counts. No Critical finding or wholesale missing current-drop feature was found. It identified one Important integration defect and one Important outstanding visual acceptance gate.

The integration defect was a private-world liquid origin mismatch. Ordinary cached water/lava gradients used missing public atlas coordinates as zero, while bridge undersides used the correct absolute private scene coordinates. At the real Blackglass Span, ordinary lava sampled RGB112.472/47.270/37.055 while the same physical point beneath the bridge sampled123.127/53.358/38.301. A renderer regression reproduced that mismatch before correction. Both ordinary materials now use the existing canonical `sectorMapOrigin`. The regression passes for actual bridge-colour equality and the shared edge with the eastern private sector. Public geometry and liquid authority are unchanged.

The visual gate remains open: final mainland desktop/phone town and hamlet captures, shores/depths, larger landmarks and continuous motion must supersede the older observations about repeated functional arrangements and angular boundaries. Eight floor panels and source coverage do not prove the requested reference transformation or town distinctiveness. This visual gate stays in the current drop.

Audit scope decisions: the next-update ferry access/new-Void gameplay tests and inherited appearance/NPC/Events/accessibility/broader-performance work remain deferred exactly as Nick directed. Decorative scenery does not introduce new quest/reward mechanics. Existing collision/topology is retained while actual presentation is assessed. No speculative performance rewrite or physical-handset claim is made. No unrequested numerical density target or unique architecture quota is imposed on every hamlet; actual distinctiveness remains a rendered acceptance question. The cost of these boundaries is that the next update and the stated native/physical acceptance remain explicitly incomplete, rather than being silently marked delivered.

# Canonical Master targeting previews — verified development checkpoint

The Master Panel now previews canonical Line, Circle, All and plural target selections through the existing native targeting authority. Previously its fixture recognized only the older area-target format, so a valid canonical Line or Circle was sent a selected unit instead of a direction or activation. Independent friendly categories could also be replaced by an enemy inferred from the legacy envelope. Plural previews showed only one target.

The fixture now respects authored categories, prefers its existing intended target, and asks the native enumerator and target resolver for eligible selections. It stops at the authored selection limit and never invents extra units to fill that limit. The fixture contains two enemies, so a three-target Volley demonstrates two available recipients. Self and a unit reference to the actor count as one selection. Zero-range drafts leave other units on distinct tiles and retain native legality failures when they cannot reach a target.

Line uses a cardinal direction; Circle and All use activation. Explicit geometry3 categories own Ground delivery. The older geometry2 Fire/Ground intent flag remains on its historical path. Friendly Ground previews place an actual allied recipient within the fixture instead of showing an empty-effect failure. The native command still decides full legality, Requirements, costs and outcomes.

Selection uses the planned Move destination without moving or executing the fixture. The normal preparation path retains the included overall Move price and free one-time Controlled prime. It performs the existing native command preparation once; target enumeration is a pure geometry step, not a second command preparation or another effect evaluator.

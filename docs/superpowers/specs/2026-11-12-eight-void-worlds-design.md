# Eight Void worlds, environment controls and coordinates

Owner additions are approved for immediate implementation in the single PR1038 graphics release. User authorizes production after quality and smoke gates. Do not ship a partial graphics-only predecessor. In-game Void playtesting is explicitly deferred until the later sea-ferry access update; do automated geometry, connectivity, discovery/privacy, rotation, authorization and persistence checks now. Do not claim deferred tests passed.

Eight separate server-authored geographies each occupy a32×24sector local map (416×216tiles,89,856cells before water/obstacles). This is a continent-scale local journey compared with the old13district layout, broadly consistent with the globe's unknown-landmass veil. Exact playable extent is measured by tests. Distinct coastlines, river/lava networks, basins, ridges, named focal districts, refuges, quiet wilderness and rare celestial/time ruins define the worlds. Names: The Inverted Reach; The Drowned Meridian; The Ruined Sun; The Shattered Horizon; The Unremembered Orchard; The Fallen Firmament; The Violet Recess; The Hourless Waste. Names are public; hidden geography stays server-only. The active realm name appears in the world view and Master panel so players can identify which map is up.

Lazy strict `void:<realm>:<column>:<row>` resolution and bounded caches avoid eager construction/sending of all6,144sectors. Separate namespaces retain each world's discoveries and all legacy13district saves. Projection includes only the actor's own realm and known nearby cells; off-realm discoveries, POIs, exits and routes must not leak. Fixed dry crater footprints do not shift as private cells reveal. Every major landmark must have a real reachable approach from the safe landing, with coherent cross-sector terrain and no stamped repeated sector crossroads.

Shared map rolls use real UTC intervals, default1,440minutes, independent of clock/weather. A seeded shared random choice among8 maps is identical for everyone and may repeat. Settings/version/audit and atomic overrides extend existing environment authority. Keep-current, return-to-random, or select a named map immediately until next roll are supported. Existing ferry phase semantics and ashore expeditions remain stable; future ferry work opts into the new map selector. No new public sea-access flow is required by this update.

Display sectors in row-major geographic grid order: public128-column atlas and local32-column Void maps; legacy private4-column districts retain appropriate local numbering. The same physical sector always receives the same number independent of filtered/loaded ground. Public `Sector N · X: x · Y: y` shows local tile coordinates; Void `Sector N · X: ? · Y: ?` masks them in ordinary gameplay. Existing internal coordinate strings remain untouched because they drive topology/globe lookup/travel. Water-only/unavailable atlas positions may have reserved numbers; never silently shift saved geography or number according to what a viewer has loaded.

A new Teleport Player tab beside Master battle recovery permits staff with existing player-management access to send the selected character to a valid mainland/currentVoid sector and localX/Y. This privileged authoring view can accept VoidX/Y even though ordinary gameplay masks them. Resolve canonical terrain on the server. Reject unknown/out-of-bounds/water/lava or unsupported private targets, active battles and in-transit ferries; terminate battle through existing recovery first. Require current target-world version/idempotent command, lock actor/target/settings consistently, recheck currentVoid at commit, cancel old travel and reveal only minimal arrival area. Preserve history/items/player progress/discoveries and audit actor, reason, from/to. Browser roles must not invoke registry or privileged teleport RPCs. Authoritative movement cannot overwrite teleport from an old state.

New additive migration needs pass local Postgres behavior/ACL checks and established production compatibility/drain guards. Do not mutate production during implementation. Reference artwork/native checks continue for mainland graphics and Master UI; no unproven physical-handset/performance closure.

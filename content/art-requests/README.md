# AUREVANE Art Requests

This directory contains structured requests for missing visual assets.

Do not place random temporary web images into production UI. If a feature needs art that does not yet exist, create an `ART_REQUEST` here using the format defined in `docs/ART_BIBLE.md` and `docs/MEDIA_PIPELINE.md`.

Requests move through: `REQUESTED` → `CANDIDATE` → `APPROVED` → `PRODUCTION`.

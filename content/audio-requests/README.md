# AUREVANE Audio Requests

This directory contains structured requests for missing music, ambience, SFX, UI audio, and other sound assets.

Do not wire random or untracked audio directly into gameplay. If a feature needs sound that does not yet exist, create an `AUDIO_REQUEST` here using `docs/AUDIO_BIBLE.md` and `docs/MEDIA_PIPELINE.md`.

Requests move through: `REQUESTED` → `CANDIDATE` → `APPROVED` → `PRODUCTION`.
